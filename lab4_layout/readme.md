# Praktikum 4 - Layout Sederhana

## Deskripsi

Praktikum ini bertujuan untuk membuat layout website sederhana menggunakan HTML dan CSS. Website terdiri dari halaman Home, About, dan Kontak dengan tampilan yang diatur menggunakan CSS.

## Penjelasan Program

### 1. File `home.html`

Halaman Home menampilkan header, menu navigasi, hero panel, kotak informasi, artikel, sidebar, dan footer. Elemen HTML digunakan untuk menyusun konten, sedangkan CSS mengatur posisi dan tampilannya.

### 2. File `about.html`

Halaman About berisi informasi tentang diri, daftar keahlian, dan portofolio. Bagian keahlian dan portofolio menggunakan elemen `div` dengan class tertentu agar tampilannya dapat diatur menggunakan CSS.

### 3. File `kontak.html`

Halaman Kontak berisi informasi untuk menghubungi pemilik website dan formulir yang terdiri dari nama lengkap, email, subjek, serta pesan. Formulir dilengkapi tombol Kirim Pesan dan atribut `required` untuk menandai kolom yang wajib diisi.

### 4. File `style.css`

File CSS digunakan untuk mengatur tampilan website, seperti warna, jenis huruf, ukuran teks, jarak, navigasi, artikel, sidebar, portofolio, dan formulir kontak. CSS juga menggunakan Flexbox untuk mengatur tata letak serta media query agar tampilan dapat menyesuaikan layar berukuran kecil.

## Cara Menjalankan

1. Buka folder praktikum di Visual Studio Code.
2. Pastikan file `home.html`, `about.html`, `kontak.html`, dan `style.css` berada dalam folder yang sesuai.
3. Buka file `home.html` menggunakan browser.
4. Klik menu navigasi untuk berpindah ke halaman lain.

## Kesimpulan

Praktikum ini memberikan pemahaman tentang penggunaan HTML untuk menyusun struktur halaman website dan CSS untuk mengatur tampilannya. Website memiliki beberapa halaman dengan fungsi berbeda serta menggunakan Flexbox dan media query untuk membantu mengatur tata letak dan menyesuaikan tampilan pada layar kecil.
