# Praktikum Box Element

## Deskripsi

Praktikum ini membahas penggunaan HTML dan CSS untuk membuat elemen kotak (_Box Element_), mengatur warna latar belakang, serta mengatur posisi elemen menggunakan properti CSS.

## Penjelasan Program

Program ini menggunakan HTML untuk membuat empat elemen div, yaitu Div 1, Div 2, Div 3, dan Div 4. Setiap elemen memiliki warna latar belakang yang berbeda, yaitu merah, kuning, hijau, dan biru.

CSS digunakan untuk mengatur tampilan dan posisi elemen dengan beberapa properti berikut:

- `float: left;` untuk membuat elemen mengapung ke sisi kiri sehingga dapat tersusun berdampingan.
- `padding: 10px;` untuk memberikan jarak antara isi dan bagian dalam elemen.
- `background` dan `background-color` untuk mengatur warna latar belakang.
- `clear: left;` untuk membuat elemen tidak berada di samping elemen sebelumnya yang menggunakan float ke kiri.
- `float: none;` untuk menghilangkan pengaturan float pada elemen tertentu.

## Cara Menjalankan Program

1. Buka Visual Studio Code.
2. Buka folder tempat file praktikum disimpan.
3. Pastikan file `lab4_box.html` sudah tersedia.
4. Buka file tersebut menggunakan browser.
5. Amati tampilan empat elemen div beserta warna dan posisi masing-masing.

## Kesimpulan

Praktikum ini menunjukkan bahwa HTML digunakan untuk membuat struktur halaman web, sedangkan CSS digunakan untuk mengatur tampilan, warna, jarak, dan posisi elemen. Dengan menggunakan properti `float`, `clear`, dan `padding`, tata letak elemen dapat diatur sesuai kebutuhan.
